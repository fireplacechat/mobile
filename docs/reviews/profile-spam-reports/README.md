# Profile spam reports

Flutter renders of the surfaces this change adds. The fixtures are fictional.
Times are UTC. The conversation images loaded the installed Windows emoji font
as a test-only fallback. That font is not bundled with the app.

The chat header has the security-code shield only. Mute, Block User and Report
Spam are on the profile, in that order. Mute uses the normal text colour. Block
and Report Spam are red. The panels are the block confirmation and the spam
report.
